╔════════════════════════════════════════════════════════════════════════════╗
║                           POWER SETUP                                      ║
╚════════════════════════════════════════════════════════════════════════════╝

Option 1: Single 7.4V LiPo Battery
──────────────────────────────────
    7.4V LiPo Battery
         │
         ├──> Motor Driver VCC (7-12V input)
         │         │
         │         └──> 5V regulator output ──> Arduino 5V pin
         │                                           │
         │                                           └──> RPLiDAR 5V
         │
         └──> GND ──> Motor Driver GND ──> Arduino GND ──> RPLiDAR GND


Option 2: Dual Power (RECOMMENDED for testing)
───────────────────────────────────────────────
    USB Power Bank (5V, 2A+)              Battery Pack (7-12V)
         │                                       │
         ├──> Arduino VIN or 5V pin              ├──> Motor Driver VCC
         │         │                             │
         │         └──> RPLiDAR 5V               │
         │                                       │
         └──> GND ─────┬─────────────────────────┘
                       │
                   COMMON GROUND (CRITICAL!)


⚠️  CRITICAL POWER NOTES:
    1. RPLiDAR needs 2A capability - USB ports often can't provide this!
    2. Motor driver MUST have separate power (not from Arduino 5V pin)
    3. ALL grounds MUST be connected together (common ground)
    4. Use thick wires (22 AWG or thicker) for motor connections


╔════════════════════════════════════════════════════════════════════════════╗
║                        QUICK TROUBLESHOOTING                               ║
╚════════════════════════════════════════════════════════════════════════════╝

LiDAR not spinning?
  → Check Pin 3 connection to MOTOR wire (orange/yellow)
  → Verify code has: analogWrite(RPLIDAR_MOTOR, 255);
  → Check 5V power can supply 2A

No LiDAR data?
  → Verify TX1 ↔ RX and RX1 ↔ TX connections
  → Try swapping TX/RX if needed
  → Check Serial Monitor baud rate is 115200

Motors not working?
  → Check motor driver has separate power
  → Verify common ground connection
  → Test with manual motor commands

Spins wrong direction?
  → Swap motor wires on motor driver outputs
  → Or modify turnRight() function in code
